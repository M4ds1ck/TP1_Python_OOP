# TP1 Python POO 🎆

[![Python Version](https://img.shields.io/badge/Python-3.x-blue)](https://www.python.org/)

Ce depot contient les exercices réalisés dans le cadre du **TP1 de Programmation Orientée Objet (POO)** en Python.  
L’objectif principal est de mettre en pratique les concepts fondamentaux de la POO tels que les classes, les objets, les attributs, les méthodes, l’encapsulation et les propriétés.

---

## 📂 Contenu du LAB TP1

### Exercice 1 — Compteur de visites
- Différenciation entre **attributs de classe** et **attributs d’instance**  
- Suivi du nombre total de visites pour toutes les pages

### Exercice 2 — Gestion d’inventaire
- Création de la classe Article avec gestion du stock et calcul de la valeur totale  
- Possibilité de journaliser les approvisionnements

### Exercice 3 — Carnet de contacts
- Gestion d’une liste d’objets Contact  
- Recherche insensible à la casse et propriétés pour accéder aux informations

### Exercice 4 — Calculatrice géométrique pour cercles
- Utilisation de propriétés pour sécuriser l’accès aux attributs  
- Calcul automatique du périmètre et de la surface  
- Possibilité d’agrandir le cercle d’un pourcentage donné

### Exercice 5 — Journal de tâches
- Gestion de fichiers avec `with` pour l’ouverture et la fermeture automatique  
- Enregistrement de tâches avec date et heure

### Exercice 6 — Convertisseur de devises
- Utilisation de méthodes statiques et de classe pour convertir euros ↔ dirhams  
- Possibilité de mettre à jour le taux de conversion dynamiquement

## 🚀 Utilisation

1. Cloner le dépôt ou télécharger le projet.
```bash
git clone https://github.com/M4ds1ck/TP1_Python_OOP.git
```
2. Aller dans le dossier de l’exercice voulu exemple :
```bash
cd TP1_Python_OOP/EXERCICE1
```
3. Lancer le script de test :
```bash
python test_competur_page.py
```
